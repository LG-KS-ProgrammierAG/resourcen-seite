Godot Game Engine

Godot ist eine freie und quelloffene Game Engine, mit der ihr eigene Spiele entwickeln könnt. Um loszulegen, müsst ihr Godot zuerst auf eurem Rechner installieren. Zum Programmieren wird GDScript verwendet – eine einfache Skriptsprache, die speziell für Godot entwickelt wurde.
